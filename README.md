# Контакты (sbe-contacts)

SBE-плагин «Контакты» — модуль контактов, вынесенный из монолита `yougile-tntn`.
Картотека контактов в виде визиток с QR-кодами (vCard) для переноса в телефон.
Синхронизация с сервером `contacts-service` (`https://epyur.fvds.ru`) через JWT из ЦУП СБЕ.

## Требования

- Установлен и включён `sbe-apstore` (ЦУП СБЕ ПМиПИР).
- Есть доступ к серверу контактов (роль выдаёт администратор; данные хранятся на
  сервере, локально — только кэш `yourbase/sbe_contacts/`).

## Использование

Откройте плагин через ЦУП СБЕ ПМиПИР → «Установленные» → «Открыть» (у sbe-contacts
собственных риббона и команд нет).

## Возможности

- Фасад «LogicTEAM.Контакты»: топбар + сайдбар (сворачивание, навигация, «Фильтры»
  по типам организации, Синхронизация) + контент.
- Контакты — визитками: имя, должность, организация, контакты в две колонки, куратор.
- Клик по визитке — разворот на месте: в правую зону встаёт QR-код (vCard 3.0),
  появляется значок ✏️ редактирования (правый нижний угол) и кнопка «⬇ PNG» для
  сохранения QR картинкой. Модалка редактирования — только по клику на ✏️.
- Создание/редактирование контактов: имя, телефон, email, организация, должность,
  тип организации (свободный текст, подсказки из локального реестра), примечание.
- Куратор контакта — автоматически последний создатель/редактор (email из ЦУП).
- Удаление контакта: куратор контакта или роль admin. Офлайн-удаление уходит в очередь
  и выполняется при следующей синхронизации.
- Поиск по имени/телефону/email/организации/должности, фильтры по типам организации.
- Синхронизация: сервер — канон, локальный кэш; несинхронизированные записи
  автоматически загружаются на сервер при синке.
